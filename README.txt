BIRTHDAY WEBSITE — QUICK START

Design: pink, cream, red, subtle polka dots, and a little matcha-green accent.

1. Open index.html in a browser to preview the website.
2. Add your photos into assets/photos and name them photo1.jpg, photo2.jpg, photo3.jpg.
3. Add an MP3 file named music.mp3 into the assets folder.
4. Edit index.html in a text editor to personalise the birthday letter and photo captions.
5. Publish the whole folder using GitHub Pages.

Keep the folder structure intact:
  index.html
  assets/music.mp3
  assets/photos/photo1.jpg
  assets/photos/photo2.jpg
  assets/photos/photo3.jpg

This version does not include the final gift section.
